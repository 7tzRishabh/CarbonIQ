# CarbonIQ

"Measure Smarter. Live Greener."

CarbonIQ is an AI-powered carbon footprint tracking platform that helps users measure, understand, and reduce their environmental impact through personalized insights and sustainability recommendations.

## Features
- **Carbon Tracking**: Accurately log transportation, food, electricity, waste, and water usage.
- **AI Coach**: Personalized insights powered by Gemini AI.
- **Dashboard**: Track your progress over time with comprehensive data visualizations.
- **Leaderboard**: Engage in community competition and gamified environmental action.

## Tech Stack
- Frontend: React, Tailwind CSS, Recharts
- Backend: Express, Node.js (via Vite)
- Database: Firebase Firestore
- AI: Google Gen AI SDK
